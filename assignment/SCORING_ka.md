### X1. სისტემის დიზაინის დიაგრამა

დახატეთ, როგორ ელაპარაკება თქვენი აპლიკაცია სერვერს. გამოიყენეთ [Excalidraw](https://excalidraw.com), [draw.io](https://draw.io), ან ფანქარი, ქაღალდი და ფოტო. სურათი შეინახეთ `docs/` ფოლდერში და აჩვენეთ README-ში.

ნახატზე უნდა ჩანდეს:

1. **ნაწილები**: ბრაუზერი თქვენი HTML, CSS და JavaScript ფაილებით, API სერვერი და `localStorage`.
2. **ყველა მოთხოვნა**, რომელსაც თქვენი აპლიკაცია აგზავნის: მეთოდი და URL, რა იწვევს მის გაგზავნას და რა ბრუნდება.
3. **მომხმარებლის ერთი მოქმედება თავიდან ბოლომდე**, დანომრილი ნაბიჯებით. მაგალითად „მომხმარებელი კრეფს `phone`-ს და აჭერს Search-ს“, დაჭერიდან ეკრანზე ბარათების გამოჩენამდე.

დახატეთ თვითონ. AI-ს მიერ გენერირებული დიაგრამა ქულას არ იღებს, დაცვაზე კი მის შესახებ გკითხავთ.
